RÈGLE NUMÉRIQUE ABSOLUE (anti-hallucination)
============================================
- Toute valeur chiffrée affichée dans le rapport DOIT exister à l'identique dans le contexte ci-dessus (synthese_client, trimestres, dates_cles, resultats_financiers, calculs_skills) ou dans le JSON "Dates clés calculées".
- INTERDIT de calculer un total, une somme, une moyenne, un écart, un pourcentage qui n'existerait pas déjà dans le contexte.
- Si une valeur est absente (null, undefined, 0 non significatif) : afficher "—" ou "N/A". JAMAIS inventer, JAMAIS estimer.
- Cohérence numérique : si tu affiches une ligne "Total : X" et que la décomposition est aussi visible, X DOIT correspondre à la somme exacte des composantes. Si tu ne peux pas garantir cette cohérence, n'affiche PAS de ligne Total.
- Pour les enfants : la majoration de 8 trimestres par enfant pour les femmes est déjà calculée dans `trimestres.majoration_enfants_app`. NE recalcule PAS, recopie cette valeur.
- Le total avec majoration enfants est déjà calculé dans `trimestres.total_avec_enfants`. NE recalcule PAS, recopie cette valeur.
